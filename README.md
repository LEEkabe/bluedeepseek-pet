# 桌宠（Desktop Pet）

用你提供的角色图做的 Windows 桌面宠物。**单文件 EXE，双击即用，不需要安装 Python / .NET / 任何依赖。**

## 使用

双击 `桌宠.exe`（或 `pet\dist\Pet.exe`）。角色出现在屏幕右下角。

| 操作 | 效果 |
|---|---|
| 左键拖动 | 移动位置 |
| 左键单击 | 轮流触发：**跳跃 → 压扁回弹 → 左右抖动**，同时随机冒出一句中文台词 |
| 鼠标滚轮 | 缩放（0.45× ～ 2.6×，以角色底边中心为锚点，不会跳位） |
| 右键 | 菜单：调整大小 / 窗口置顶 / 互动一下 / 退出 |
| 菜单 → 退出 | 关闭程序（没有标题栏，只能从这里退出） |

窗口是**无边框、始终置顶、逐像素透明**的，只在角色和气泡上响应鼠标 ——
点空白处会直接穿透到下面的窗口，不会挡住你干活。


## 重新构建

```powershell
.\build.ps1
```

流程：Python + Pillow 去背 → 生成图标 → 用 **Windows 自带的 csc.exe**
（`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`）编译。
**不需要联网，不需要装任何包。**

产物：`dist\Pet.exe`，同时会用它生成 `build\preview.png`
（左半边洋红、右半边深色，方便一眼看出有没有白边或空洞）。

## 目录

```
pet/
├── build.ps1              一键构建
├── src\Pet.cs             全部程序代码（单文件）
├── tools\make_sprite.py   去背 + 出图标 + 出预览图
├── build\                 中间产物（sprite.png / pet.ico / preview.png / 截图）
└── dist\Pet.exe           成品
```

## 已知说明

- 首次启动时 Windows 可能弹一次 SmartScreen（因为 EXE 没有代码签名），
  选"仍要运行"即可。这是所有未签名自制程序的通例。
- 运行目录下**只有崩溃时**才会写 `pet-debug.log`，正常使用不会产生文件。
- 角色图是你提供的素材，随程序内嵌分发；程序代码本身可自由修改。


## 使用说明
怎么开始
-----------------------------------------
1. 双击「桌宠.exe」就能运行，角色会出现在屏幕右下角。
2. 不需要安装任何东西，不需要联网。
3. 没有标题栏，也不会出现在任务栏里。

操作
----------------------------------------
· 左键拖动 ······ 移动位置
· 左键单击 ······ 互动（跳跃 / 压扁回弹 / 左右抖动 轮流出现），
                   同时随机冒出一句台词
· 鼠标滚轮 ······ 放大缩小
· 右键 ·········· 菜单：调整大小 / 窗口置顶 / 互动一下 / 退出

怎么退出
----------------------------------------
右键角色 → 退出。

首次运行会弹提示
----------------------------------------
Windows 可能弹出蓝色的「Windows 已保护你的电脑」。
这是因为它没有花钱买数字签名，不是病毒。
点「更多信息」→「仍要运行」即可，以后不再提示。

其他
----------------------------------------
· 角色以外的空白区域可以直接点穿，不会挡住你操作其他窗口。
· 窗口默认始终置顶，可在右键菜单里关掉。
· 正常使用不会产生任何文件；只有出错时才会在旁边生成
  pet-debug.log，用来排查问题。
· 删除这个文件夹就等于卸载干净，不写注册表、不留垃圾。

适用系统
----------------------------------------
Windows 10 / 11 直接可用（系统自带需要的运行库）。
